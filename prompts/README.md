# 提示词模板目录 (Prompts Directory)

本目录包含用于驱动大语言模型（如 Qwen3-8B 与 Qwen2.5-7B）自动合成 Python 单元测试的提示词模板模块。

---

## 核心实现

- **`templates.py`**:
  - **功能**: 实现符合学术严谨标准的**严格单向信息隔离 Prompt 模板**；
  - **信息边界**: 仅向大模型注入未打补丁的 `base_commit` 源码上下文与目标函数接口说明，严禁注入任何官方回归测试、参考测试或修复补丁，确保生成的测试完全基于公开 API 规范自主推断；
  - **指令约束**: 明确要求模型输出独立、可执行的 pytest 测试函数，严禁省略断言或生成伪造的占位用例。
